# 🌍 MUN Simulation Platform

A modern, interactive website for Model United Nations (MUN) simulation and learning. This platform features a stunning design with comprehensive study guides, committee information, and delegate profiles.

## 🚀 Features

- **Homepage** - Beautiful hero section with animated backgrounds and feature showcase
- **Study Guides Page** - Comprehensive learning resources with filtering and search
- **People & Committees Page** - Detailed information about UN committees and active delegates
- **Interactive Elements** - Smooth animations, hover effects, and dynamic content
- **Responsive Design** - Works perfectly on desktop, tablet, and mobile devices
- **Modern UI/UX** - Gradient backgrounds, glassmorphism effects, and smooth transitions

## 📁 File Structure

```
├── index.html          # Main homepage
├── study-guides.html   # Study guides page with resources
├── people.html         # People & committees page
├── styles.css          # All styling and animations
├── script.js           # Interactive JavaScript functionality
└── README.md           # This file
```

## 🎨 Design Features

- **Color Scheme**: Dark theme with vibrant gradients (purple, pink, blue, green)
- **Typography**: Poppins for body text, Orbitron for headings
- **Animations**: Floating shapes, fade-in effects, hover transitions
- **Effects**: Glassmorphism, gradient text, glowing elements

## 🛠️ How to Use

1. **Open the Website**: Simply open `index.html` in your web browser
2. **Navigate**: Use the navigation menu to explore different pages
3. **Study Guides**: Filter by category or search for specific topics
4. **People & Committees**: Browse committees and filter delegates by region
5. **Interactive Features**: Hover over cards, click buttons, and explore animations

## 📱 Pages Overview

### Homepage (index.html)
- Hero section with animated background
- Feature cards showcasing platform capabilities
- Live simulation interface preview
- Statistics counter animation
- Footer with links

### Study Guides (study-guides.html)
- Searchable guide library
- Category filters (Security, Economic, Environmental, Human Rights)
- Guide cards with metadata (duration, pages, topics)
- Quick tips section for MUN success

### People & Committees (people.html)
- UN Committees overview (Security Council, GA, ECOSOC, etc.)
- Active delegates with country flags
- Regional filters (P5, Europe, Asia, Africa, Americas)
- Delegate statistics and committee assignments

## 🎯 Interactive Features

- **Animated Counters**: Stats animate when scrolled into view
- **Filter System**: Filter guides and delegates by category/region
- **Search Functionality**: Real-time search in study guides
- **Smooth Scrolling**: Anchor links with smooth scroll behavior
- **Parallax Effects**: Background shapes move on scroll
- **Mobile Menu**: Hamburger menu for mobile navigation
- **Hover Animations**: Cards lift and glow on hover

## 💡 Customization

You can easily customize:
- **Colors**: Edit CSS variables in `:root` section of `styles.css`
- **Content**: Modify HTML files to add/remove sections
- **Animations**: Adjust animation durations and effects in CSS
- **Functionality**: Extend JavaScript in `script.js`

## 📝 Notes

- All text content is placeholder and can be customized
- Images/emojis are used for visual elements (can be replaced with actual images)
- The design is fully responsive and works on all screen sizes
- No backend required - works as a static website
